SIL'MIR TELEGRAM TRANSLATOR — TEST VERSION

Файлы лежат в одной папке. Подпапки не нужны.

1. В Telegram открой @BotFather.
2. Создай бота командой /newbot.
3. Скопируй токен.
4. Открой config.py обычным текстовым редактором.
5. Замени ВСТАВЬ_ТОКЕН_СЮДА на токен.
6. Запусти:

   python bot.py

На Windows иногда команда называется:

   py bot.py

Ничего через pip ставить не надо. Используется стандартная библиотека Python.

ПРОВЕРКА БЕЗ TELEGRAM:

   python test_translator.py

ЛОГИКА НЕИЗВЕСТНЫХ СЛОВ:
Если русского слова нет в словаре, бот не придумывает перевод, а записывает его
латиницей алфавита Sil'mir. После перевода через два пустых абзаца появляется
Telegram-спойлер:

   этих слов нет: слово1, слово2

Словарных пар собрано: 7918.

ОГРАНИЧЕНИЕ ЭТОЙ ВЕРСИИ:
Это первая rule-based версия. Словарь полный, но сложный синтаксис русского пока
не разбирается как машинный переводчик. Базовые местоимения, настоящее время,
частые глаголы, отрицание, часть падежей Sil'mir и морфологический разбор уже есть.
